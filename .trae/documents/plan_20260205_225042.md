## Verification
1.  **Question Type Switching**:
    *   Switching types now instantiates the correct `domainData` and `interactionData` classes.
    *   The form dynamically updates to show fields defined in those classes.
2.  **Interaction Mode Switching**:
    *   Changing interaction mode preserves `domainData` (e.g., the graph) but resets `interactionData` (e.g., the sliders).
3.  **Validation**:
    *   The "Expected Answer" section is now dynamic based on the selected `AnswerValidationType`.
    *   Validators can now parse both the old JSON format and the new schema-generated structure.
